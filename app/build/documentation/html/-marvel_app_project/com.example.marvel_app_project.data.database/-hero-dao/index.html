interface HeroDao

HeroDao is used to manage interaction between RoomDB and HeroRepository. The functions of this interface have the same functional as the functions of Hero Repository.

HeroDao используется для управления взаимодействием между RoomBD и HerpRepository. Функции этого интерфейса имеют идентичный функциям HeroRepository функционал
