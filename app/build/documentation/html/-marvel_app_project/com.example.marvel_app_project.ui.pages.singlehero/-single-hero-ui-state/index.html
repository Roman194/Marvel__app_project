SingleHeroUiState

sealed interface SingleHeroUiState

SingleHeroUiState is a sealed interface that store all possible UI states for the SingleHeroScreen. It transfers them from the ViewModel to UI inside 1 structure what is matches with the MVI pattern logic. See about MVI pattern

Сеалед-интерфейс SingleHeroUiState хранит все данные о возможных UI-состояниях для SingleHeroScreen. Он передаёт эти данные из ViewModel в UI внутри единой структуры, которая совпадает с логикой MVI-паттерна
