SingleHeroViewModel

class SingleHeroViewModel @Inject constructor(val repository: HeroRepository) : ViewModel

SingleHeroViewModel is a class that manage SingleHeroScreen state and transfer data and events between Repository and UI screen. To work with data layer it uses coroutines inside function updateHeroForSingleHero.

Класс SingleHeroViewModel управляет состоянием экрана SingleHeroScreen и передаёт данные и события между репозиторием и экраном. Для работы с дата-слоем оно используетс корутины внутри функции updateHeroForSingleHero.

конструктор использует Dagger Hilt DI Inject для соответствия ViewModel entity c Repositor-ным.

параметр repository используется для работы с дата-слоем. параметр heroesUiState используется для хранения текущего состояни экрана SingleHeroScreen.
