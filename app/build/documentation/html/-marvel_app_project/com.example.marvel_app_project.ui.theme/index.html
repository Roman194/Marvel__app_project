Marvel_app_projectTheme
Link copied to clipboard
@Composable
fun Marvel_app_projectTheme(darkTheme: Boolean = isSystemInDarkTheme(), dynamicColor: Boolean = true, content: @Composable () -> Unit)

Marvel_app_projectTheme is a Composable function that applies a Material3 theme to the app. It supports dark and light themes, as well as dynamic colors on Android 12 and above. The status bar color is also adjusted based on the theme. It wraps the MaterialTheme composable to provide consistent theming across the app. It consist of as generated by Android Studio theme settings as well as some files with custom settings: Sizes, Spaces and Shapes. See more about Jetpack Compose and Material3
