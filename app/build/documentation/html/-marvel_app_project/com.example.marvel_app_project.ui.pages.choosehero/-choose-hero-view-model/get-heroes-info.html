getHeroesInfo

fun getHeroesInfo()

getHeroesInfo function is used to get all heroes from Repository layer with the usage of coroutines. It updates heroesUiState with 1 of 2 possible states: ChooseHeroesUiState.Success or ChooseHeroesUiState.Error depending on the result of the request to Repository layer. In case of ChooseHeroesUiState.Error it transfers heroes from DB to show them on UI. In case of ChooseHeroesUiState.Success it transfers all heroes from DB but with fresh update from Marvel API. It also determines background color and visible part of hero name for each hero. See functions toDetermineBackgroundColor and toDetermineHeroNameVisiblePart. getHeroesInfo is called during initialization of this app as a manager for ChooseHeroScreen state (ChooseHeroScreen is the started screen of this app).

getHeroesInfo-функция используется для получения данных о всех героях из репозитория с использованием корутин. В зависимости от результата запроса с data-слоя, она обновляет heroesUiState одним из двух возможных состояний: ChooseHeroUiState.Success or ChooseHeroUiState.Error. В случае ChooseHeroUiState.Error она передаёт всех героев из БД для вывода их в UI. В случае ChooseHeroUiState.Success оно передаёт всех героев из БД, но с новым апдейтом данных с сервера. Вызывается во время инициализации приложения или когда пользователь кликает на возврат на странице SingleHeroScreen. Также в этой функции задаётся цвет заднего фона и видимой части имени героев
